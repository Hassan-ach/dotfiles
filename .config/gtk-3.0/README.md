# 🎨 GTK 3 / GTK 4 Styling (`.config/gtk-3.0` & `.config/gtk-4.0`)

GTK toolkit appearance for Wayland apps (Thunar, Nautilus, and other GTK apps).

---

## 📂 Files (mirrored across both versions)

- **`settings.ini`**: Theme selection — `Stylish-Dark-Laptop` theme, `Papirus-Dark` icons, `Iosevka Nerd Font Medium 11`, default cursor, dark preference.
- **`gtk.css`**: Dynamic color CSS **generated by Matugen** (`templates/gtk/colors.css` → both `gtk-3.0/gtk.css` and `gtk-4.0/gtk.css`).
- **`gtk-3.0/bookmarks`**: GTK file-chooser sidebar bookmarks (Notes, Music, Documents, …).

## ⚡ Pipeline

- Matugen rewrites `gtk.css` on every wallpaper change, so GTK app accents follow the theme.
- **Folder icons**: `papirus-accent` (invoked by `wallset`) hue-shifts `Papirus-Dark` folder icons to the same accent — GTK and Qt file managers stay wallpaper-synced.
- Actual theme/icon/font values are also relevant to `nwg-look` (which manages them via its own export flags).
