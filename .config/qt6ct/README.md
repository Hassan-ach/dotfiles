# ⚙️ Qt6 Configuration (`.config/qt6ct`)

Qt6 appearance styling configuration utility.

---

## 📂 Files

- **`qt6ct.conf`**: Style, icon theme, standard dialogs, font, and `color_scheme_path` — points to the Matugen-generated `~/.local/share/color-schemes/Matugen.colors`.
- **`style-colors.conf`**: Style-level color overrides.
- **`colors/`**: Static color schemes (`Catppuccin-Latte.conf`, `Catppuccin-Mocha.conf`, `dr.conf`) — manual alternatives; Matugen does **not** write into this directory.

> For Qt5, see the sibling [qt5ct README](../qt5ct/README.md).
