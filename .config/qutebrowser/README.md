# 🌐 Qutebrowser Configuration (`.config/qutebrowser`)

Keyboard-focused, Vim-like web browser configuration.

---

## 📂 Files

- **`config.py`**: Python configuration defining keybindings, search engines, zoom, and tab settings.
- **`solarized-everything-css/`**: **Git submodule** tracking [alphapapa/solarized-everything-css](https://github.com/alphapapa/solarized-everything-css) — generated user-stylesheets cycled by the `,a`/`,d`/`,g`/`,s`/`,r` keybinds (`,ap` apprentice, `,dr` darculized, `,gr` gruvbox, `,sd`/`,sl` solarized, `,rp` rosepine).
  > ⚠️ The `,rp` binding references `css/rosepine/rosepine-all-sites.css`, but upstream has no rosepine variant — that binding silently does nothing (pre-existing config quirk).
- **`themes/palette.py`**: Dynamic color scheme palette generated by Matugen (`templates/qtbrowser.py`) — generated & gitignored.
- **`themes/select_theme.py`** / **`back.py`** / **`color_palette.py`** / **`custom-font.css`**: Theme-selection machinery invoked by the `,t` keybind.
- **`quickmarks`**: Saved quick bookmark shortcuts.
- **`bookmarks/urls`**: Standard bookmarks.
- **`autoconfig.yml`**: GUI setting overrides.
- **`qsettings/QtProject.conf`**: Qt-level browser settings.
