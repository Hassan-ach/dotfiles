# 🖥️ Tmux Terminal Multiplexer Configuration

Configuration for Tmux terminal multiplexer integrated with Matugen themes, resurrect session persistence, and custom sessionizers.

---

## 📂 Files

> **Note:** The Tmux config lives at the **repository root** (stowed to `$HOME`), not in this directory. This README is only documentation.

- **`~/.tmux.conf`** (repo root: `.tmux.conf`): Main Tmux configuration file.
- **`~/.tmux_colors.conf`** (repo root: `.tmux_colors.conf`): Dynamic status line color palette generated by Matugen (`templates/terminal/tmux_colors.conf`).

---

## ⚙️ General Settings

- **Prefix**: `CTRL + b` (secondary prefix: `CTRL + Space`)
- Base index starts at `1`, mouse on, `escape-time 0`, vi copy mode, aggressive resize, extended keys, focus events.
- **Status bar position**: top.

## ⌨️ Full Keybindings Reference (Prefix Key: `CTRL + b`)

### Window & Pane Navigation (Vim-style)
| Keybinding | Action |
| :--- | :--- |
| `PREFIX + h` | Select Pane Left |
| `PREFIX + j` | Select Pane Down |
| `PREFIX + l` | Select Pane Right |
| `CTRL + h/j/k/l` | Seamless Vim-Tmux Navigator window focus switching (works inside Neovim too) |

> ⚠️ `PREFIX + k` is **not** pane-up: it is rebound below to the dev session launcher (`bind k` from the navigation block is overwritten by `bind -r k`). Use `CTRL + k` (vim-tmux-navigator) to move focus up.

### Session Management & Launchers
| Keybinding | Action |
| :--- | :--- |
| `PREFIX + f` | Open Interactive Sessionizer (`tmux-sessionizer`) |
| `PREFIX + k` | Open Dev Project Session Launcher (`tmux-dev-session`) |
| `PREFIX + r` | Reload `~/.tmux.conf` Configuration & Notify |
| `PREFIX + CTRL + j` | Interactive FZF Session Switcher Popup |
| `PREFIX + CTRL + n` | Prompt to Create New Named Session |

### Splits
| Keybinding | Action |
| :--- | :--- |
| `PREFIX + \` or `PREFIX + \|` | Split Horizontal (side-by-side, current path) |
| `PREFIX + -` or `PREFIX + _` | Split Vertical (top/bottom, current path) |

### Vi Copy Mode & Buffers
| Keybinding | Action |
| :--- | :--- |
| `[` | Enter Copy Mode (vi keys; `PREFIX + v` is **not** bound) |
| `v` (in copy mode) | Begin Selection |
| `y` (in copy mode) | Copy Selection & Cancel |
| `PREFIX + p` | Paste Tmux Buffer |

## 🔌 Plugins Installed (TPM)

- **`tmux-plugins/tpm`**: Tmux Plugin Manager.
- **`tmux-plugins/tmux-resurrect`**: Persist and restore Tmux environments across system reboots (captures Neovim sessions and pane contents).
- **`tmux-plugins/tmux-continuum`**: Continuous saving of Tmux environment.
- **`christoomey/vim-tmux-navigator`**: Seamless navigation between Neovim splits and Tmux panes.

---

## 🛠️ How to Edit & Customize

1. **Edit Config**: Modify `~/.tmux.conf` (repo root `.tmux.conf`).
2. **Reload Settings**: Press `PREFIX + r` inside Tmux.
3. **Install Plugins**: Press `PREFIX + I` to install TPM plugins.
