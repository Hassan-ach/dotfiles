# 📊 Waybar Configuration (`.config/waybar`)

Highly customizable Wayland top bar for Hyprland.

---

## 📂 Files

- **`config`**: JSON structure defining bar layout, enabled modules, and positions.
- **`style.css`**: Styling stylesheet importing `colors.css`.
- **`colors.css`**: Dynamic Material You palette generated by Matugen (`templates/waybar-colors.css`).

---

## 💡 Modules Enabled

- **Left**: `hyprland/workspaces`, `hyprland/window`
- **Center**: `clock` (Date & Time)
- **Right**: `cpu`, `memory`, `pulseaudio` (Volume), `tray`

---

## 🛠️ Utilities

- Toggle Waybar on demand using `SUPER + SHIFT + T` (triggers `~/.local/bin/waybarToggle.sh`).
