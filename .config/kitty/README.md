# 🐱 Kitty Terminal Configuration (`.config/kitty`)

GPU-accelerated terminal emulator configuration integrated with Matugen theme engine.

---

## 📂 Files

- **`kitty.conf`**: Core terminal options (fonts, opacity, cursor, remote control, shell).
- **`colors.conf`**: Dynamic color scheme generated by Matugen template (`templates/terminal/kitty.conf`), included via `include ./colors.conf`.
- **`themes/`**: Manual theme library (see below).

---

## ⚙️ Key Settings

- **Font**: Iosevka Nerd Font, size **18.0** (`cell_width` modified to 95%).
- **Window Padding**: `0` (width and height).
- **Background Opacity**: `0.7` with `dynamic_background_opacity yes` — adjust live with the keybinds below.
- **Shell**: `shell tmux` — every Kitty window starts inside Tmux.
- **Remote Control**: enabled (`allow_remote_control yes`, `listen_on unix:/tmp/kitty`) so scripts/tools can drive Kitty over the socket.
- **Cursor**: block, blinking, with cursor trail (`cursor_trail 10`).
- **Integration**: Matugen automatically overwrites `colors.conf` on wallpaper updates.

## ⌨️ Keybindings

| Key | Action |
| :--- | :--- |
| `Ctrl + =` / `Ctrl + -` | Increase / decrease font size |
| `Super + U` | Set background opacity to 0.0 (fully transparent) |
| `Super + Shift + U` | Reset background opacity to default |
| `Super + Shift + I` | Set background opacity to 1.0 (opaque) |
| `Ctrl + Shift + J` / `K` | Increase / decrease opacity by 0.05 |

## 🎨 Manual Themes (`themes/`)

Six bundled themes you can switch to with `kitty +kitten themes` or by pointing `include` at one of:

`black_metal_gorgoroth`, `cyberdream`, `rose-pine`, `rose-pine-dawn`, `rose-pine-moon`, `tokyo-night`

> Matugen-generated `colors.conf` takes precedence while the wallpaper pipeline is active.

---

## 🛠️ How to Edit & Customize

1. **Terminal options**: Edit `~/.config/kitty/kitty.conf`.
2. **Colors**: Regenerate via `wallset` / `matugen image <wallpaper>` — do not hand-edit `colors.conf`.
3. Reload: press `Super + Shift + R` in Hyprland or restart Kitty.
