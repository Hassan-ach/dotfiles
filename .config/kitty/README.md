# 🐱 Kitty Terminal Configuration (`.config/kitty`)

GPU-accelerated terminal emulator configuration integrated with Matugen theme engine.

---

## 📂 Files

- **`kitty.conf`**: Core terminal options (fonts, padding, cursor, bell, URL handling).
- **`colors.conf`**: Dynamic color scheme generated by Matugen template (`templates/terminal/kitty.conf`).

---

## ⚙️ Key Settings

- **Font**: Iosevka Nerd Font (Size 13).
- **Window Padding**: `12 12` for clean visual margins.
- **Background Opacity**: Enabled for glassmorphic dark themes.
- **Integration**: Matugen automatically overwrites `colors.conf` on wallpaper updates.
