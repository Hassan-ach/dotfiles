# 🐙 Lazygit Configuration (`.config/lazygit`)

Terminal UI client for Git.

---

## 📂 Files

- **`config.yml`**: GUI preferences — rounded borders and a hardcoded rose-pine color palette (border colors, selected line, cherry-pick colors).

> Note: the theme is static (not Matugen-driven), and there are no paging or keybinding overrides in this config.
