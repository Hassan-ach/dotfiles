# 🚀 Rofi Launcher & Menu (`.config/rofi`)

Rofi application launcher, window switcher, and visual wallpaper picker interface.

---

## 📂 Files

- **`config.rasi`**: Main Rofi configuration — `modi` (`drun,filebrowser,window`), icons, fzf sorting, `window-command` (`wmctrl`), and core theming.
- **`grid.rasi`**: Responsive multi-column grid layout preset (available for grid-style menus; the wallpaper picker currently injects its own inline `-theme-str` from `wallset`).
- **`style.rasi`**: Full theme stylesheet.
- **`colors.rasi`**: Dynamic color variables generated by Matugen (`templates/rofi.rasi`).

---

## 🎯 Usage & Modes

- **App Launcher**: `SUPER + D` (`rofi -show drun`)
- **Window Switcher**: `SUPER + TAB` (`rofi -show window`)
- **File Browser**: `rofi -show filebrowser`
- **Visual Wallpaper Grid**: `wals` (runs `wallset`, which builds its own 4-column thumbnail grid via `rofi -theme-str`)
- **Power / Clipboard / WiFi Menus**: `SUPER + SHIFT + Q` / `V` / `W` (custom Rofi dialogs — see `.local/bin/README.md`)
