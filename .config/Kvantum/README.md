# 🟪 Kvantum Theme Engine (`.config/Kvantum`)

Kvantum Qt theme engine configuration — the actual engine behind `qt5ct`/`qt6ct`'s `kvantum-dark` style.

---

## 📂 Files

- **`kvantum.kvconfig`**: Engine config — sets the active theme to `caelus`.
- **`caelus/caelus.kvconfig`**: Theme geometry/colors — **generated by Matugen** (`templates/kvantum/caelus.kvconfig`).
- **`caelus/caelus.svg`**: Theme SVG slice map — **generated by Matugen** (`templates/kvantum/caelus.svg`).

## ⚡ Pipeline

Every wallpaper change (`wallset` → `matugen`) rewrites both files in `caelus/`, recoloring all Qt/Kvantum apps (Brave dialogs, Telegram, OBS, etc.).
