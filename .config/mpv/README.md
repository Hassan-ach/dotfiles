# 🎬 MPV Media Player (`.config/mpv`)

Media player configuration and custom input shortcuts.

---

## 📂 Files

- **`mpv.conf`**: Hardware video acceleration, audio output, subtitle styling, and cache buffers.
- **`input.conf`**: Custom mouse wheel and keyboard shortcuts.

---

## ⌨️ Keybindings

- `WHEEL_UP` / `WHEEL_DOWN`: Seek +10s / -10s
- `SHIFT + WHEEL_UP` / `DOWN`: Volume +2 / -2
- `l` / `h`: Seek +5s / -5s
- `k`: Pause / Play toggle
- `j`: Volume -2
- `CTRL+l` / `CTRL+h`: Next / Previous playlist item
