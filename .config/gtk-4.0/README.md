# 🎨 GTK 4 Styling (`.config/gtk-4.0`)

GTK 4 half of the GTK toolkit styling — full details in the combined [GTK 3 / GTK 4 README](../gtk-3.0/README.md).

---

## 📂 Files

- **`settings.ini`**: Theme selection — `Stylish-Dark-Laptop` theme, `Papirus-Dark` icons, `Iosevka Nerd Font Medium 11`, default cursor, dark preference (mirrors `gtk-3.0/settings.ini`).
- **`gtk.css`**: Dynamic color CSS **generated by Matugen** (`templates/gtk/colors.css` writes to both `gtk-3.0/gtk.css` and `gtk-4.0/gtk.css`).

## ⚡ Pipeline

Matugen rewrites `gtk.css` on every wallpaper change; `papirus-accent` keeps the shared `Papirus-Dark` folder icons in sync. See [gtk-3.0/README.md](../gtk-3.0/README.md).
