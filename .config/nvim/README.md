# ⚡ Neovim IDE (`.config/nvim`)

Modern, ultra-fast Lua-based Neovim configuration built with Lazy.nvim, NvChad Base46 highlights, Treesitter, and LSP.

---

## 📂 Architecture

- **`init.lua`**: Main entry point, plugin manager setup, autocommands, and LSP log level settings (`WARN`).
- **`lazy-lock.json`**: Lockfile for exact plugin commit versions.
- **`lua/`**:
  - `vimopts.lua`: Native vim options, keymaps, custom filetype definitions (`gotmpl`, `xsl`, `mdx`).
  - `chadrc.lua`: Base46 theme configuration (`matugen` theme, transparency, statusline).
  - `mappings/`: Language-specific keymaps (`init.lua`, `rust.lua`, `sql.lua`).
  - `plugins/`: ~60 modular Lazy.nvim plugin specifications (LSP, Conform formatting, Treesitter, Telescope, Gitsigns, Laravel, AI, Markdown, and more). `allsync.lua` wires up WallSync.
  - `utils/`: Helpers (dashboard, color overrides, icons).
  - `snippets/`: Snippet definitions (`latex.lua`, `notes.lua`).
  - `float_term.lua`, `texpresso.lua`, `icons.lua`, `lualine-rose-pine.lua`: supporting modules.
- **`ftplugin/`**: Per-filetype config (`java.lua`, `tex.lua`).
- **`pywal/`**: **Git submodule** tracking [NvChad/pywal](https://github.com/NvChad/pywal) — the WallSync plugin (lazy-loaded via `lua/plugins/allsync.lua`) plus the Matugen template inputs referenced in `.config/matugen/config.toml`. Initialized by `install.sh` (`git submodule update --init`).

> The old Python `chadwal.py` watcher is **gone** — WallSync (Lua) replaced it. It watches `~/.cache/wal/base46-{dark,light}.lua` and `~/.cache/wal/colors` (generated by Matugen's `nvim`/`nvimlight`/`pywal` templates) and hot-reloads the theme when they change.

## ⌨️ Essential Keybindings

- `<space>`: Leader Key
- `gd`: Go to Definition
- `gr`: Find References
- `<leader>ca`: Tiny Code Actions
- `<leader>e`: Floating Diagnostic
- `[e` / `]e`: Jump Diagnostic (note: both currently map to `goto_next`)
- `<leader>y` / `<leader>Y`: Yank to System Clipboard
- `<leader>la` / `<leader>lr`: Laravel Artisan & Routes

---

## 🛠️ How to Edit & Customize

1. **Plugin specs**: Add/edit files in `~/.config/nvim/lua/plugins/`.
2. **Theme**: `chadrc.lua` (Base46) — colors regenerate via the wallpaper pipeline.
3. **Keymaps**: `lua/vimopts.lua` (global) and `lua/mappings/` (language-specific).
