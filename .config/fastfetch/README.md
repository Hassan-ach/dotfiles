# ⚡ Fastfetch Configuration (`.config/fastfetch`)

System information fetch tool layout configuration.

---

## 📂 Files

- **`config.jsonc`**: Module layout definition — `title`, `os`, `kernel`, `packages`, `display`, `wm`, `terminal`, `cpu`, `gpu`, `memory`, `disk`, install-age `command` (days since system install), `uptime`, border decorations, and a `colors` swatch row.
- **`ArchLogo.txt`**: Custom Arch Linux ASCII art logo — **not referenced** by `config.jsonc` (its `logo.source` is empty), kept as an optional asset.

> Note: there is no `shell` module; the separator is ` : `.
