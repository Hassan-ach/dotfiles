# ⚙️ Qt5 & Qt6 Configuration (`.config/qt5ct` & `.config/qt6ct`)

Qt5 and Qt6 appearance styling configuration utilities.

---

## 📂 Files

- **`qt5ct.conf`** / **`qt6ct.conf`**: Style, icon theme, standard dialogs, and font configurations for Qt applications.
- **`colors/`**: Matugen color schemes generated for Qt dialogs and applications.
