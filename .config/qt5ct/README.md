# ⚙️ Qt5 Configuration (`.config/qt5ct`)

Qt5 appearance styling configuration utility.

---

## 📂 Files

- **`qt5ct.conf`**: Style (`kvantum-dark`), icon theme, standard dialogs, font, and `color_scheme_path` — points to the Matugen-generated `~/.local/share/color-schemes/Matugen.colors`.
- **`colors/`**: Static color schemes (`Catppuccin-Latte.conf`, `Catppuccin-Mocha.conf`, `dr.conf`) — manual alternatives; Matugen does **not** write into this directory.

> For Qt6, see the sibling [qt6ct README](../qt6ct/README.md).
