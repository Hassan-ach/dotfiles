# 🎨 nwg-look Configuration (`.config/nwg-look`)

GTK3/GTK4 visual theme, icon, and cursor configuration manager for Wayland.

---

## 📂 Files

- **`config`**: Export behavior flags — `export-settings-ini`, `export-gtkrc-20`, `export-index-theme`, `export-xsettingsd`, `export-gtk4-symlinks`, and Flatpak override toggles.

> Note: the actual GTK theme/icon/font/cursor values live in `.config/gtk-3.0/settings.ini` and `.config/gtk-4.0/settings.ini`, not here.
