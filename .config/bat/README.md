# 🦇 Bat Configuration (`.config/bat`)

Syntax highlighting `cat` replacement configuration.

---

## 📂 Files

- **`config`**: Core options — theme selection (`--theme="Catppuccin Frappe"`), paging, syntax mappings.
- **`themes/`**: Local tmThemes — `Matugen.tmTheme` (generated by Matugen `templates/terminal/bat.tmTheme`), `black-metal-gorgoroth`, `rose-pine`, `Sublime Snazzy`, `tokyonight_night`.

> Note: the configured `Catppuccin Frappe` theme is not in `themes/` — it ships **embedded in the bat binary** of this install (custom build), so it resolves even though it isn't a file. All themes are listed by `bat --list-themes`.
