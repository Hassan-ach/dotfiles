# 📋 Herdr Configuration (`.config/herdr`)

Herdr CLI/TUI configuration and theme merging.

---

## 📂 Files

- **`config.toml`**: Core Herdr configuration.
- **`theme-colors.toml`**: Dynamic colors generated by Matugen (`templates/terminal/herdr-theme.toml`), merged into `config.toml` by `~/.local/bin/herdr-merge-theme`.
- **`cheatsheet.md`**: Command reference cheat sheet.
