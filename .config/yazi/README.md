# 📁 Yazi File Manager (`.config/yazi`)

Blazing fast terminal file manager configuration.

---

## 📂 Files

- **`theme.toml`**: Dynamic theme palette generated by Matugen (`templates/terminal/yazi.toml`).

> ⚠️ `theme.toml` is a **generated output** and is not tracked in this repo — it appears after the first wallpaper/theme run (`wallset` or `matugen image …`). Yazi also has no `yazi.toml`/`flavor` overrides here; defaults are used.

---

## ⚡ Integration

- Triggered via alias `y` $\rightarrow$ `yazi`, or `yy` to follow the exit directory.
- Matugen dynamically updates file type icon colors, active directory highlights, and status lines.
