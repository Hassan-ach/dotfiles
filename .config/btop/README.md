# 📈 Btop Resource Monitor (`.config/btop`)

Resource monitor configuration and Matugen theme integration.

---

## 📂 Files

- **`btop.conf`**: Core settings — shown boxes (`mem net proc cpu`, GPU box not enabled), process sorting (`memory`), and update refresh rate.
- **`themes/matugen.theme`**: Dynamic theme file generated by Matugen (`templates/terminal/btop.theme`).
- **`themes/rose-pine.theme`**: Static alternative theme.
