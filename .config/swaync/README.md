# 🔔 SwayNotificationCenter (`.config/swaync`)

Notification daemon and control center for Wayland.

---

## 📂 Files

- **`config.json`**: Structure defining widget positions, notification behavior, and action buttons.
- **`style.css`**: CSS styling rules for notifications, control center panel, and icons.

---

## 🛠️ Usage

- Invoked automatically by Hyprland (`startup.lua`).
- Reloaded automatically by `walset-backend` on wallpaper changes.
